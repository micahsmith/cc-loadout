# Technical Writing Style Guide

Version 1.

Apply these rules to all prose you write. They cover prose only: code and quotes are excluded from
these rules. Defer to the user if they ask for a different writing style.

Clarity and ease of comprehension is the goal. Prefer clarity over brevity. Prefer a plain sentence
over an elgant one.

## Rules

1. Keep each subject beside its verb. Put nested clauses in their own sentences.
2. Each sentence should make one and only one claim.
3. Begin a sentence with what the reader already knows. End it with what is new.
4. Use one term for one thing, and reuse that term everywhere.
5. State what is true.
6. Do not use double negatives.
7. Repeat the noun when "it", "this", or "that" refer back more than a few words.
8. Choose more common words. Define a technical term at first use, or replace it.
9. Name the actor and the action. Write "the check failed" instead of "a failure of the check occurred".
10. Name the relation between sentences with "because", "however", or "so".
11. Say how many items follow before you list them.
12. State conclusions first. Provide support after.
13. Give every item in a list the same grammatical shape.
14. Put countable or comparable content in a table or list.
15. Keep each sentence under about 25 words.
